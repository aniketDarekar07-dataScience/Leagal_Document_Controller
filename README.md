# ⚖️ Legal Contract Management System

A complete contract management solution with user authentication, role-based access, version control, approval workflow, and audit trail.

## ✨ Features

- 🔐 User Authentication (Register/Login)
- 👥 Role-Based Access (Admin, Legal, Viewer)
- 📄 Contract Upload & Management
- 🔄 Version Control
- ✅ Approval Workflow
- 📊 Audit Trail
- 📱 Responsive Dashboard

## 🛠️ Tech Stack

| Layer | Technology |
|-------|------------|
| Backend | FastAPI (Python) |
| Database | MySQL |
| ORM | SQLAlchemy |
| Frontend | HTML, CSS, Bootstrap |
| Templates | Jinja2 |
